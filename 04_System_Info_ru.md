# Информация о системе

## Система

| Команда | Описание |
|---------|----------|
| `uname -a` | Полная информация о системе |
| `uname -r` | Версия ядра |
| `hostnamectl` | Имя хоста и ОС |
| `lsb_release -a` | Информация о дистрибутиве |
| `neofetch` | Красивый вывод информации |
| `uptime` | Время работы и нагрузка |
| `date` | Текущая дата и время |
| `timedatectl` | Время и часовой пояс |

## Аппаратура

| Команда | Описание |
|---------|----------|
| `lscpu` | Информация о CPU |
| `lscpu \| grep "Model name"` | Модель процессора |
| `free -h` | Использование RAM |
| `lspci` | Все PCI устройства |
| `lspci \| grep VGA` | Видеокарта |
| `lsusb` | USB устройства |
| `lsblk` | Блокочные устройства |
| `sudo dmidecode` | Подробная инфо о железе |

## Диски и память

| Команда | Описание |
|---------|----------|
| `df -h` | Использование дисков |
| `du -sh /path` | Размер директории |
| `fdisk -l` | Таблица разделов |
| `lsblk -f` | Файловые системы |

## Процессы и загрузка

| Команда | Описание |
|---------|----------|
| `top` | Мониторинг процессов |
| `htop` | Улучшенный top |
| `ps aux` | Все запущенные процессы |
| `journalctl -b` | Логи текущей загрузки |
| `dmesg` | Сообщения ядра |
| `systemctl list-units` | Статус сервисов |

## Температура

```bash
# Если установлен lm_sensors
sudo pacman -S lm_sensors
sudo sensors-detect
sensors

# Для SSD
sudo pacman -S smartmontools
sudo smartctl -a /dev/sda
```

## Шпаргалка

```bash
# Быстрая информация о системе
neofetch

# Сколько оперативной памяти
free -h

# Сколько места на диске
df -h

# Какое железо
lscpu && lspci && lsusb

# Нагрузка на систему
uptime && top -bn1 | head -5
```
