# Процессы

## Просмотр процессов

| Команда | Описание |
|---------|----------|
| `top` | Мониторинг в реальном времени |
| `htop` | Улучшенный top (нужно установить) |
| `ps aux` | Все запущенные процессы |
| `ps aux \| grep name` | Найти процесс по имени |
| `pstree` | Дерево процессов |
| `pgrep name` | PID процесса по имени |
| `pidof name` | PID процесса |

## Управление процессами

| Команда | Описание |
|---------|----------|
| `kill PID` | Остановить процесс |
| `kill -9 PID` | Принудительно остановить |
| `killall name` | Остановить все процессы с именем |
| `pkill name` | Остановить по паттерну |
| `kill -STOP PID` | Приостановить |
| `kill -CONT PID` | Продолжить |

## Приоритеты

| Команда | Описание |
|---------|----------|
| `nice -n -5 command` | Запустить с высоким приоритетом |
| `nice -n 5 command` | Запустить с низким приоритетом |
| `renice -n -5 PID` | Изменить приоритет |
| `renice -n 5 PID` | Понизить приоритет |

## Запуск в фоне

```bash
# Запустить в фоне
command &

# Запустить в фоне (отвязать от терминала)
nohup command &

# Запустить в новой сессии
setsid command

# Переключить текущий процесс в фон
Ctrl+Z
bg
```

## systemd (сервисы)

| Команда | Описание |
|---------|----------|
| `systemctl status name` | Статус сервиса |
| `systemctl start name` | Запустить |
| `systemctl stop name` | Остановить |
| `systemctl restart name` | Перезапустить |
| `systemctl enable name` | Автозапуск |
| `systemctl disable name` | Отключить автозапуск |
| `systemctl list-units` | Все сервисы |
| `systemctl list-unit-files` | Все доступные сервисы |

## Шпаргалка

```bash
# Посмотреть топ-10 процессов по памяти
ps aux --sort=-%mem | head -10

# Посмотреть топ-10 процессов по CPU
ps aux --sort=-%cpu | head -10

# Убить процесс по имени
pkill -f "process_name"

# Запустить в фоне и отвязать
nohup python script.py &

# Статус сервиса
systemctl status NetworkManager
```
