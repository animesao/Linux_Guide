# Основные команды Linux

## Навигация

| Команда | Описание |
|---------|----------|
| `pwd` | Показать текущую директорию |
| `ls` | Список файлов |
| `ls -la` | Список всех файлов (включая скрытые) с подробной информацией |
| `cd /path` | Перейти в директорию |
| `cd ..` | Вернуться на уровень выше |
| `cd ~` | Перейти в домашнюю директорию |
| `cd -` | Вернуться в предыдущую директорию |

## Работа с файлами

| Команда | Описание |
|---------|----------|
| `touch file` | Создать пустой файл |
| `mkdir dir` | Создать директорию |
| `mkdir -p a/b/c` | Создать вложенные директории |
| `cp file1 file2` | Скопировать файл |
| `cp -r dir1 dir2` | Скопировать директорию рекурсивно |
| `mv file1 file2` | Переменовать/переместить файл |
| `rm file` | Удалить файл |
| `rm -r dir` | Удалить директорию |
| `rm -rf dir` | Удалить директорию без подтверждения |
| `ln -s target link` | Создать символическую ссылку |

## Просмотр файлов

| Команда | Описание |
|---------|----------|
| `cat file` | Вывести содержимое файла |
| `less file` | Просмотр файла с прокруткой |
| `head -n 20 file` | Первые 20 строк |
| `tail -n 20 file` | Последние 20 строк |
| `tail -f file` | Следить за файлом в реальном времени |
| `wc -l file` | Подсчитать количество строк |
| `file file` | Определить тип файла |

## Права доступа

| Команда | Описание |
|---------|----------|
| `chmod 755 file` | Установить права (rwxr-xr-x) |
| `chmod +x file` | Сделать файл исполняемым |
| `chmod -R 755 dir` | Рекурсивно изменить права |
| `chown user:group file` | Изменить владельца |

### Расшифровка прав

| Число | Права |
|-------|-------|
| 7 | rwx (чтение + запись + исполнение) |
| 6 | rw- (чтение + запись) |
| 5 | r-x (чтение + исполнение) |
| 4 | r-- (только чтение) |
| 0 | --- (нет прав) |

Формат: ` Владелец / Группа / Остальные `

## Поиск файлов

| Команда | Описание |
|---------|----------|
| `find / -name "*.txt"` | Найти файлы по имени |
| `find / -size +100M` | Файлы больше 100MB |
| `find / -mtime -7` | Изменённые за последние 7 дней |
| `which command` | Путь к исполняемому файлу |
| `whereis command` | Где находится команда |

## Редактирование

| Команда | Описание |
|---------|----------|
| `nano file` | Открыть в nano (простой редактор) |
| `vim file` | Открыть в vim |
| `echo "text" > file` | Записать текст в файл (перезапись) |
| `echo "text" >> file` | Дописать текст в конец файла |

## Горячие клавиши (bash)

| Комбинация | Описание |
|------------|----------|
| `Ctrl+C` | Прервать текущую команду |
| `Ctrl+D` | Выйти из терминала |
| `Ctrl+R` | Поиск по истории команд |
| `Ctrl+A` | Перейти в начало строки |
| `Ctrl+E` | Перейти в конец строки |
| `Ctrl+L` | Очистить экран |
| `Tab` | Автодополнение |
| `↑ / ↓` | Навигация по истории |

## Шпаргалка

```bash
# Копировать файл в домашнюю
cp /etc/config.conf ~/

# Найти все .conf файлы
find /etc -name "*.conf"

# Последние 50 строк лога
tail -n 50 /var/log/pacman.log

# Удалить все .tmp файлы
find /tmp -name "*.tmp" -delete
```
